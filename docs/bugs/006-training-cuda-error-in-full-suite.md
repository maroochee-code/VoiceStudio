# 006. 전체 테스트 중 목소리 학습이 가끔 CUDA 오류로 실패

- 날짜: 2026-11-17 / 단계: 7단계 테스트 중 발견
- 증상: 전체 테스트(65개)에서 실제 학습 테스트만 `[rank0]: ... Compile with TORCH_USE_CUDA_DSA ...`로 실패. 같은 테스트를 단독으로 돌리면 통과, 전체를 다시 돌려도 통과(재현 안 됨).
- 원인: **확인 필요** (오류 전문이 잘려 기록되지 않음). 유력한 추정: 앞선 테스트들이 같은 프로세스에서 GPU를 써서 CUDA 기본 공간(수백 MB)이 남아 있고, 바탕화면 프로그램(브라우저 등)이 쓰는 VRAM까지 더해져 학습(배치 3) 중 메모리가 모자람.
- 대응:
  1. 메인 프로그램의 VRAM 측정을 torch → nvidia-smi로 바꿔, 측정만으로 CUDA 공간을 차지하지 않게 함 (`app/stt.py free_vram_mb`)
  2. SoVITS/GPT 학습 단계가 실패하면 배치 크기를 절반으로 줄여 한 번 재시도 (`SovitsTrainer._with_retry`)
  3. 학습 시작 시 남은 GPU 메모리를 기록하고 4.5GB 미만이면 경고
- 다시 생기면: 진행 기록의 "GPU 남은 메모리" 값과 실패 메시지 전문을 이 문서에 추가할 것.
- 관련 파일: `app/sovits.py`, `app/stt.py`, `tests/test_stage5_sovits.py`
