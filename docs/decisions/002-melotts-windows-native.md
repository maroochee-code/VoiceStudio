# 002. MeloTTS를 Docker 없이 윈도우 가상환경에 직접 설치

날짜: 2026-11-17

## 고른 것
- MeloTTS를 메인 가상환경(.venv)에 직접 설치하고, 윈도우 문제 3가지는 우리 코드와 설치 스크립트로 우회(버그 기록 001~003).
- 한국어 형태소 분석기: `python-mecab-ko`(별도 폴더 설치) + 실행 시 g2pkk에 바꿔 끼우기.

## 왜
- 공식 문서는 윈도우에 Docker를 권하지만, Docker Desktop은 설치·메모리 부담이 크고 툴이 엔진을 직접 켜고 끄기(지휘자 로직) 어려움.
- 같은 가상환경이면 위스퍼와 멜로를 한 프로그램 안에서 바로 불러 쓸 수 있음.
- MeloTTS·g2pkk 원본을 고치지 않으므로 업데이트해도 우리 수정이 지워지지 않음.

## 다른 후보
- Docker: 공식 권장이지만 무겁고 연동이 복잡.
- eunjeon: 2020년 이후 관리가 중단되어 파이썬 3.10용 설치 파일이 확인되지 않음.
- MeloTTS 소스 직접 수정: 업데이트 때마다 다시 고쳐야 함.
