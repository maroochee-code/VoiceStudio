# 003. GPT-SoVITS 설치 방식과 모델 버전

날짜: 2026-11-17

## 고른 것
- **별도 가상환경** `engines/GPT-SoVITS/.venv` (Python 3.10, PyTorch 2.6.0 + CUDA 12.4)
- 모델 버전 **v2Pro** (예비로 v2 기본 모델도 받아 둠)
- 학습: GPT-SoVITS 웹 화면을 쓰지 않고, 그 안의 준비·학습 스크립트를 우리 툴이 직접 순서대로 실행 (`app/sovits.py`)
- 합성: GPT-SoVITS의 `api_v2.py` 서버를 필요할 때만 켜고, 끝나면 끔 (엔진 관리자가 관리)
- 받아쓰기(학습 문장 텍스트 만들기)는 이미 있는 우리 위스퍼를 사용

## 왜
- 메인 환경은 PyTorch 2.5.1(멜로 호환), GPT-SoVITS는 transformers 4.5x가 PyTorch 2.6 이상을 요구 → 한 환경에 둘 수 없음.
- v2Pro: 공식 설명상 v2와 VRAM 사용이 비슷하면서 품질이 더 좋음. v3/v4/v5는 모델이 4배 이상 커서 6GB에 부담.
- 공식 윈도우 설치는 conda+cmake로 소스 빌드를 하는데, 이 PC에는 컴파일러가 없음 → 빌드가 필요한 3개 패키지를 대체(버그 기록 005).
- 학습 배치 크기 3: GPT-SoVITS 웹 화면이 6GB GPU에 주는 기본값(VRAM GB ÷ 2)과 같음.

## 다른 후보
- 공식 통합 패키지(7z, 수 GB, 자체 파이썬 포함): 설치는 쉽지만 툴에서 학습·합성을 자동으로 연결하기 어렵고 용량이 큼.
- conda 설치: conda가 C:에 캐시를 쌓고, 컴파일러 설치(Visual Studio)가 추가로 필요.
