# 004. 대화 AI 모델과 음성 대화 흐름

날짜: 2026-11-17

## 고른 것
- 기본 모델 **gemma3:4b** (약 3.3GB, Ollama 모델 폴더 `D:\LocalAI\AImodels`에 저장). 화면에서 설치된 다른 모델로 바꿀 수 있음.
- 답변마다 `keep_alive=0` → 답이 끝나면 모델이 바로 GPU에서 내려감 (기획서 규칙)
- 음성 대화 중 **위스퍼는 CPU**로 실행
- qwen3 계열은 `think=false`로 생각 과정 출력을 끔

## 왜
- gemma3:4b: 기획서 후보 중 하나이고 한국어 답변 품질 확인(시험 질문 "한국의 수도" → 서울, 이전 대화 기억). qwen3:4b는 생각 과정을 출력해 음성 답변이 느려짐.
- 위스퍼 CPU: GPU는 Ollama와 SoVITS가 번갈아 써야 하는데, 위스퍼까지 GPU에 올리면 질문마다 엔진 교체가 한 번 더 생김. small 모델은 CPU로도 짧은 질문을 몇 초 안에 처리.
- 답변마다 모델을 다시 올리므로 질문당 약 20~25초(멜로 목소리 기준, 2026-11-17 측정). 더 빠르게 하려면 keep_alive를 늘려야 하지만 기획서 규칙(VRAM 보호)을 우선함.

## 다른 후보
- qwen3:4b: 생각 끄기 가능하지만 기본 출력이 길고 느림.
- exaone3.5:7.8b(이미 설치됨): 한국어가 강하지만 4.8GB로 6GB VRAM에 빠듯함 → 목록에서 직접 고르면 사용 가능.
