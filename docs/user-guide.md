# VoiceStudio 사용·기능 설명서

집 PC에서 인터넷 없이 돌아가는 음성 AI 툴입니다. 말을 글자로 바꾸고, 글자를 목소리로 읽고, 내 목소리를 학습해 그 목소리로 읽게 하고, AI와 음성으로 대화합니다.

## 1. 켜고 끄기
- **켜기:** 바탕화면의 **VoiceStudio** 아이콘을 더블클릭합니다. 30초 정도 지나면 브라우저가 열립니다.
  - 브라우저가 열리지 않으면 주소창에 `http://127.0.0.1:7860`을 입력하세요.
  - 이미 켜져 있을 때 아이콘을 다시 누르면 브라우저 화면만 새로 열립니다.
- **끄기:** 작업 표시줄의 검은 창(VoiceStudio)을 닫습니다. 켜져 있던 엔진도 모두 같이 꺼집니다.
- **접속 범위:** 내 PC에서만 접속됩니다. 다른 기기에서는 열 수 없습니다.

## 2. 화면(탭)별 기능

### 녹음
| 할 일 | 방법 |
|---|---|
| 브라우저로 녹음 | 마이크 버튼 → 녹음 → 정지 (처음엔 브라우저가 마이크 권한을 물어봄 → 허용, 마이크는 K66 선택) |
| K66으로 바로 녹음 | 녹음 시간(초)을 정하고 **K66으로 녹음 시작** |
| WAV로 저장 | **WAV로 저장** → `data/recordings/` |
| 학습 샘플로 보내기 | 목소리 이름을 쓰고 **학습용 샘플로 보내기** → `data/samples/<이름>/`. 결과 칸에 지금까지 모인 총 길이와 학습 가능 여부(60초 이상)가 나옴 |

> 학습용 녹음 요령: 조용한 곳에서, 한 번에 10~30초씩 여러 문장을 또박또박 읽어 총 1~3분 모으세요. 문장 사이에 잠깐 쉬면 자동으로 잘 잘립니다.

### 말 → 글자
- 녹음하거나 오디오 파일(mp3, wav 등)을 올리고 **글자로 바꾸기**를 누릅니다.
- **모델:** small은 빠르고, medium은 더 정확하지만 느립니다(처음 쓸 때 약 1.5GB를 받음).
- **실행 위치:** 자동을 추천합니다. GPU 여유가 없으면 CPU로 알아서 바뀝니다.
- 결과 칸 오른쪽 위 버튼으로 복사하고, **텍스트 파일로 저장**으로 `data/transcripts/`에 저장합니다.

### 글자 → 말
- 목소리를 고르고, 문장을 입력하고, 속도(0.5~2배)와 저장 형식(WAV/MP3)을 정한 뒤 **읽기**를 누릅니다.
- **목소리 종류:**
  - **기본 (멜로):** 가볍고 빠릅니다(CPU 사용).
  - **학습: 이름:** 내가 학습시킨 목소리입니다(GPU 사용, 처음 읽을 때 30초쯤 준비).
  - **샘플: 이름:** 참고 음성 하나만 듣고 흉내 냅니다(학습 없이).
- 결과는 자동으로 재생되고 `data/outputs/`에 저장됩니다. 결과 칸에 그 목소리의 라이선스가 함께 표시됩니다.

### 음성 대화
- 대화 AI 모델(기본 gemma3:4b)과 답변 목소리를 고릅니다.
- 마이크로 말하고 정지하면 자동으로 질문이 전송됩니다. 글자로 써서 **보내기**를 눌러도 됩니다.
- 이전 대화를 기억합니다. 새로 시작하려면 **대화 기록 지우기**를 누릅니다.
- **걸리는 시간:** 멜로 목소리는 질문당 약 20~30초입니다. 학습·샘플 목소리는 GPU를 바꿔 쓰느라 더 걸립니다.

### 목소리 학습
1. **샘플 폴더**에서 녹음 탭에서 보낸 폴더를 고릅니다. 샘플 상태 칸에 ✅가 떠야 학습할 수 있습니다.
2. **저장할 목소리 이름**을 정합니다.
3. 반복 횟수를 정합니다. 기본값(SoVITS 8, GPT 15)을 추천하고, 늘리면 더 닮지만 오래 걸립니다.
4. **학습 시작**을 누르면 진행 기록이 실시간으로 나옵니다. 1~2분 분량 샘플 기준 약 5~15분 걸립니다.
5. 끝나면 아래 **학습한 목소리로 읽기**나 글자→말 탭에서 사용합니다.

> 학습 중에는 다른 GPU 기능(위스퍼 GPU, 대화 AI, 학습 목소리 읽기)을 쓸 수 없습니다. 멜로 읽기는 됩니다.

### 목소리 관리
- **목소리 표:** 모든 목소리의 출처, 라이선스, 상업적 사용 가능 여부를 보여줍니다.
- **샘플 목소리 등록:** 3~10초 음성과 그 문장을 넣고 출처·라이선스를 적습니다. 문장을 비워두면 위스퍼가 받아씁니다.
- **라이선스 메모 고치기:** 학습·샘플 목소리의 출처, 라이선스, 상업적 사용 여부를 수정합니다.
- 무료 샘플 데이터(KSS, AI 허브)와 라이선스는 [voice-samples.md](voice-samples.md)를 보세요. **KSS는 상업적 사용이 불가합니다.**

### 엔진 상태
- 각 엔진이 켜졌는지, GPU/CPU 중 어디에 있는지, VRAM을 얼마나 쓰는지 5초마다 보여줍니다.
- 엔진마다 켜기/끄기 버튼이 있고, **모두 끄기**로 메모리를 한 번에 비웁니다.

## 3. 파일이 저장되는 곳 (모두 D:)
| 폴더 | 내용 |
|---|---|
| `data/recordings/` | 녹음 원본 |
| `data/samples/<이름>/` | 학습용 샘플 |
| `data/transcripts/` | 말→글자 결과 |
| `data/outputs/` | 만든 음성(WAV/MP3) |
| `data/voices/trained/` | 학습한 목소리 |
| `data/voices/samples/` | 샘플 목소리 |
| `models/` | 위스퍼·멜로 등 모델 |
| `D:\LocalAI\AImodels` | Ollama 모델 |

## 4. 자주 나오는 문제
| 화면 메시지 | 해결 |
|---|---|
| 마이크 녹음에 실패했습니다 | K66 연결 확인 → 윈도우 설정 > 개인정보 > 마이크 접근 허용 |
| GPU 메모리가 부족합니다 | 엔진 상태 탭에서 **모두 끄기** 후 다시 시도, 또는 실행 위치를 CPU로 |
| 지금 '목소리 학습' 중이라… | 학습이 끝날 때까지 기다리거나 **학습 취소** |
| 학습 샘플이 부족합니다 | 녹음 탭에서 같은 이름으로 샘플을 더 보내기(총 60초 이상) |
| '…' 모델이 없습니다 | PowerShell에서 `ollama pull gemma3:4b` |
| Ollama 서버를 켜지 못했습니다 | 시작 메뉴에서 Ollama 실행 후 다시 시도 |
| MP3로 저장하려면 ffmpeg가 필요합니다 | PowerShell에서 `winget install Gyan.FFmpeg` |

## 5. 다시 설치하기
1. `scripts\install.ps1`: 메인 프로그램(위스퍼·멜로·화면)을 설치합니다.
2. `scripts\install_sovits.ps1`: 목소리 학습(GPT-SoVITS)을 설치합니다.
3. `scripts\make_shortcut.ps1`: 바탕화면 아이콘을 만듭니다.

실행 방법: 파일을 마우스 오른쪽 버튼으로 클릭 → **PowerShell에서 실행**. 또는 `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`
