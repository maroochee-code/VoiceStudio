# 샘플 목소리 넣는 방법과 라이선스

## 폴더 구조
```
data/voices/
├─ trained/<내부이름>/   학습한 목소리 (gpt.ckpt, sovits.pth, ref.wav, voice.json, license.json)
└─ samples/<이름>/       샘플 목소리
   ├─ ref.wav           3~10초 한 문장 음성 (더 길면 앞 10초만 사용)
   ├─ ref.txt           그 음성에서 말한 문장
   └─ license.json      출처 · 라이선스 · 상업적 사용(가능/불가/확인 필요) · 메모
```
가장 쉬운 방법은 웹 화면 **목소리 관리** 탭에서 "샘플 목소리 등록"을 쓰는 것입니다. 이렇게 하면 위 파일이 자동으로 만들어집니다.

## 샘플 목소리는 어떻게 읽나요?
샘플 목소리는 따로 학습하지 않습니다. GPT-SoVITS 기본 모델(v2Pro)이 참고 음성 하나를 듣고 비슷하게 따라 읽습니다(제로샷 방식). 학습한 목소리보다 닮은 정도는 떨어지지만 바로 쓸 수 있습니다. 더 닮게 하려면 해당 음성을 1분 이상 모아 **목소리 학습** 탭에서 학습하세요.

## 무료 샘플 데이터 (2026-11-17 확인)
| 데이터 | 라이선스 | 상업적 사용 | 받는 방법 |
|---|---|---|---|
| KSS (Korean Single Speaker, 제작 Kyubyong Park) | CC BY-NC-SA 4.0 (Kaggle에 표시된 값) | **불가** (출처 표시, 같은 조건으로 공유) | Kaggle 로그인 후 다운로드, 약 4.3GB |
| AI 허브 음성 데이터 | 데이터마다 이용약관이 다름 | **확인 필요** | aihub.or.kr 회원가입 → 데이터별 이용 신청 → 승인 후 다운로드 |
| 직접 녹음한 내 목소리 | 본인 소유 | 가능 | 녹음 탭 |

> 다운로드와 회원가입은 사용자가 직접 해야 합니다. 받은 파일 중 3~10초짜리 문장 하나를 골라 등록하세요(KSS는 `kss/1/1_0000.wav` 같은 파일과 `transcript.v.1.x.txt`의 문장을 함께 쓰면 됩니다. 파일 이름 규칙은 **확인 필요**).
